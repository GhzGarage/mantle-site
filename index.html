The problem

Unreal Engine can build worlds nothing else can touch. Sharing one has never been the easy part.

Publishing a multiplayer game normally means packaging a build, standing up servers, and asking players to download something new for every world they want to try. That gap between a finished level and a friend actually playing it is what Mantle closes.

Publishing today

  • Package and export a full game build for every world
  • Find, configure, and pay for your own server hosting
  • Ask players to download a multi-gigabyte installer per world
  • Ship an update, and everyone has to download it again

Publishing on Mantle

  • Build your level in the Unreal Editor, the way you already do
  • Press Publish — your world uploads in seconds, not hours
  • Players open one shared app and join instantly
  • Every update reaches everyone the moment they join

Gameplay

Worlds that do something — not just look good.

Creators can script real gameplay into a place — rules, interactions, quests, custom game modes — and Mantle doesn't lock you into one way of doing it.

  • Start simple, in Luau. The default scripting language is Luau — the same friendly, beginner-approachable language Roblox creators already write in. If you've scripted a door, a gun, or a quest before, you already know the shape of it here.
  • Or bring the language you already use. Write gameplay in JavaScript or TypeScript if that's more your speed, or in Python if that's what you already know. All three can work together in the same world.
  • Safe for every player, no matter the language. Every script runs in the same sealed sandbox. A creator's logic can never touch another player's computer, reach outside the game, or bring down anyone else's session.
  • Server rules, client feel. Scoring and anything players shouldn't be able to cheat lives safely on the server, while local scripts handle the responsive, moment-to-moment feel of a world.
VaultDoor.script 
function onPlayerTouch(player)
    door:Open()
    playSound("vault_unlock")
end

function onMatchStart()
    roundTimer:start(180)
    scoreboard:reset()
end

FAQ

Common questions

Do I need to know how to code to play?

No. Playing on Mantle means installing the app and joining a world — no different from any other multiplayer game.

Do I need to know how to code to create?

Not to get started. You can build and publish a world visually in the Unreal Editor. Scripting is there for when you want real gameplay logic, and it's designed to be approachable from day one — but it isn't required to publish a place.

Do I need to already know Unreal Engine?

To publish worlds, yes — Mantle is built for people already comfortable in the Unreal Editor. Playing worlds someone else made requires nothing more than installing the app.

What platforms will it launch on?

PC first, through Steam and the Epic Games Store, with players from both able to play together.

What will it cost?

Still being finalized. The plan is to keep playing free, the same way most platforms like this work.

When can I try it?

Mantle is in active development right now. We'll share dates as we get closer to a public test.

Live You can build a world from static meshes, materials and textures in your own project, whether you made them yourself or they came from a Fab pack. You never upload them by hand: when you publish, the plugin finds every mesh and material the level uses that isn't in Mantle's built-in library, prepares it for Mantle and uploads anything new.

Before you start

  • You need the Mantle plugin and to be signed in with a creator token.
  • Only Static Mesh Actors are published. Skeletal meshes, Blueprint actors, landscape and foliage aren't. See What you can place.
  • Sounds from your project can't be used yet, and your own vehicles are coming later.

Getting your assets into a world

  1. Bring the assets into your project

    Add the Fab pack to your project, or import your own meshes and textures, as you normally would in Unreal. Nothing about them needs to change for Mantle.

  2. Place them in the level

    Drag each Static Mesh into the level so it becomes a Static Mesh Actor. If a pack only gives you Blueprints, open the Blueprint and place the meshes it uses instead. You can change materials on the actor's slots as usual; a slot with no material uses Unreal's default material.

  3. Set collision and shadows on the actor

    The actor's Collision Enabled decides how players meet it: No Collision publishes as none, Query Only as overlap, and anything else as blocking. Cast Shadow is kept too.

  4. Save your assets

    Save the level and any meshes or materials you changed. Unsaved assets still publish, but they're prepared again on every publish, which is slower. See The conversion cache.

  5. Run Check this place

    Choose Tools → Mantle → Check this place. It checks every mesh and material from your project once, however many actors use it. Errors must be fixed before you can publish. Warnings tell you what will look different in Mantle, but don't stop anything. See Messages and how to fix them.

  6. Publish

    Choose Tools → Mantle → Publish (or Save to Mantle for a private draft). The Mantle Publish tab opens and shows each step. You can keep working while it runs.

What players see

Meshes

  • Full detail: players see the mesh at full detail.
  • Nanite: players see a Nanite mesh's fallback mesh. If it looks too coarse, raise Fallback Triangle Percent in the mesh's Nanite settings. If it's over the triangle limit, lower it.
  • Collision: a blocking or overlap mesh collides using its own triangles. Simple collision shapes set up on the mesh in Unreal aren't used.

Materials

When you publish, Mantle converts each material to work in the game. This works for any material, including material instances and graphs built from material functions.

  • Kept: base colour, normal, roughness, metallic, ambient occlusion and emissive (with its strength, up to 100).
  • Blend modes: Opaque, Masked (with its opacity mask clip value) and Translucent. Other blend modes become ordinary translucency.
  • Two Sided is kept.
  • Unlit materials become a glowing material that lighting still touches.

Some effects can't be kept. Check this place names each one as a warning, and the material still publishes:

Textures

  • Textures are at most 2048 on the longest side. Larger ones are scaled down when you publish, keeping their shape. Detail finer than that is lost.
  • Each texture file must fit in 8 MB. If one is too big, it's compressed harder or scaled down, with a warning.
  • Every texture is screened before a place can go live with it.
  • If one image is used for two different jobs, such as colour in one material and a normal map in another, one of them may be left out. See the upload messages.

The conversion cache

The plugin keeps what it has prepared in your project's Saved/Mantle/AssetCache folder, so a later publish only prepares what changed.

  • Only saved assets are kept. An asset with unsaved changes is prepared every time until you save it.
  • A plugin update or a different engine version may convert everything again once.
  • It's safe to delete the folder. Everything is simply converted again on the next publish.

Updating or replacing an asset

  • To change an asset, edit it in Unreal, save it and publish again. Only what changed is uploaded.
  • To replace an asset, swap it in the level (or on the actor's material slot) and publish again. The new one is uploaded like any other.
  • Servers already running keep the revision they started with, so players in them see the old version until the server empties. See Revisions.
  • If you edit the level while a publish is running, the plugin prepares and uploads what's new before saving. If the level keeps changing, it stops with "The level kept changing while it was being published. Pause editing for a moment and choose Publish again; nothing is uploaded twice."

If a file is rejected or removed

  • Rejected in screening or review: the place can't go live with it. Replace the texture (or the material or mesh that uses it), or remove what uses it, then publish again.
  • Waiting for a moderator: nothing goes live until it's approved. Choose Publish again once it is. Nothing is uploaded twice.
  • Removed by a moderator: moderators can remove a file from your account, usually after a licence complaint (for example a Fab pack you don't have the rights to). After that it can't be uploaded or used again, and your world's next publish is stopped until you replace it or remove what uses it.
Only use assets you have the rights to

Everything you upload is tied to your account. Use your own work, or Fab and marketplace content whose licence lets you use it in your game.

Upload limits

Each account can upload up to 5,000 meshes, materials and textures and 2 GiB per hour. Files your account already has on Mantle aren't sent again, so they don't count. A big pack's first publish can reach the limit. When it does, Publish pauses by itself and shows "Mantle's hourly upload limit is reached. Uploading continues by itself at HH:MM (in about N minutes); you can keep working meanwhile." If the wait would be longer than about an hour, it stops instead and tells you when to try again. Everything uploaded so far is kept. See Official hosting for the other limits.

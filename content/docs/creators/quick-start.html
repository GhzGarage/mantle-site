This page takes you from an empty Unreal project to a published world your friends can join. Each step links to the page with the full details.

What you need

  • Unreal Engine 5.8 from the Epic Games Launcher, on Windows. See What you need.
  • In progress The Mantle plugin. It's in early access (version 0.1.0, beta) and isn't publicly available yet. Planned The plugin will be available on Fab. Once you have it, check that Mantle Core is turned on in Edit → Plugins, then restart the editor. You'll know it's working when Tools has a Mantle section.
  • A Mantle account. Mantle is in closed testing on Steam and the Epic Games Store. Start the Mantle game from either store and you're signed in automatically. See Signing in.

Your first world

  1. Make a creator token

    In the Mantle game, open Settings → Account → Creator tokens, give the token a name and choose Create. It's shown once, so copy it straight away. See Signing in to publish.

  2. Sign in from the editor

    In Unreal, choose Tools → Mantle → Sign in with creator token... and paste your token. The menu then shows "Signed in as [your name]". The editor forgets the token when it closes, so you'll paste it again next time.

  3. Start a new place

    Make a new empty level and save it with the name you want players to see: your world takes the level's name (up to 80 characters). Then choose Tools → Mantle → Start a new place. It adds a baseplate, a spawn point and a sun, and tells you "Build from here, then use 'Check what players receive' to check your work."

  4. Build something

    Drag meshes from the built-in library (/Engine/BasicShapes and /Game/LevelPrototyping) into the level and arrange them. Players arrive at a Player Start: the new place already has one, and you can add more. See What you can place and Built-in library.

  5. Add a script (optional)

    Make a Scripts/Server folder next to your level and add a file, such as the hello example in Five-minute start. For a hazard that reacts when players touch it, see the kill brick in Tags connect scripts to things. Scripting is in preview.

  6. Set Max Players

    Choose Tools → Mantle → Place settings and set Max Players (1 to 100, default 16) in the Details panel. See Place settings for respawning and community servers.

  7. Check this place

    Choose Tools → Mantle → Check this place and fix anything it lists. When you see "No problems found. This place is ready to publish." you're ready. See What "Check this place" catches.

  8. Publish

    Choose Tools → Mantle → Publish. Add a note if you like when it asks "What changed in this version?", then watch the Mantle Publish tab. When it's done you'll see "Published revision 1. Anyone can join it now." If it stops, the tab says why. See How publishing works and What stops a publish.

  9. Find it and join

    In the Mantle game, type your world's name in the "Search worlds and creators" box. Open the world and press "PLAY". See Finding worlds and Joining a world.

  10. Invite your friends

    Published worlds are public, so friends can search for it too. Once you're in, friends on Steam or Epic can join you with the Join button in the Steam or Epic overlay. Planned Invites and a Join button inside Mantle. See Friends and presence.

To change your world, edit the level and choose Publish again. Each publish makes a new revision, and new games start on the latest one. See Revisions.

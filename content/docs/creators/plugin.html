Mantle Core is the Unreal Engine plugin you use to make things for Mantle. It adds Mantle's tools to the editor: build a place in an ordinary Unreal level, check it, test it in the Mantle game on your own PC, and upload it. It also turns your avatars, clothing, emotes and vehicles into Mantle items. This page covers installing the plugin and finding your way around it. Each section links to the page with the full details.

What the plugin does

  • Builds places. Start a new place, edit its settings and drop in Mantle actors such as spawn points, weapon spawns and vehicle spawns. See Building a place.
  • Checks your work. "Check this place" lists anything Mantle can't publish and why, and "Check what players receive" shows what players will get. Scripts and UI documents are checked for mistakes too. See What "Check this place" catches.
  • Converts with Epic's own tools. Avatars, clothing, hair, emotes and avatar items are prepared with Epic's plugins that ship with the engine, such as MetaHuman Creator, IK Rig, Groom and glTF Exporter. Your meshes and materials are converted for players when you publish. See Custom meshes and materials.
  • Tests your place. Test Locally runs the level you have open in the Mantle game on your PC. See Testing with Test Locally.
  • Uploads and publishes. Save a private draft, or publish a new revision that players can join. See Publishing and managing worlds.
  • Helps you script. A Scripts panel, visual Script Graphs and type definitions for your code editor. See Scripting.

  • glTF Exporter, IK Rig, Geometry Script, Groom, MetaHuman SDK, MetaHuman Core Tech and Chaos Cloth Asset Editor Core.
  • MetaHuman Creator and Chaos Outfit Asset, which Epic marks as Beta.

Installing and turning it on

Live Mantle Core is free on Fab for Unreal Engine 5.8 on Windows. This is version 0.1.0 (beta). Get it from Mantle Core on Fab.

  1. Add it to your engine

    On Mantle Core on Fab, add Mantle Core to your library, then install it to Unreal Engine 5.8 from the Epic Games Launcher (Fab Library → Install to Engine). Fab plugins install into the engine, not into one project, so every 5.8 project can use it.

  2. Turn it on in your project

    Open your project, choose Edit → Plugins, search for Mantle Core (in the "Mantle" category), check it and restart the editor. Any blank or existing 5.8 project works.

  3. Check it's working

    The Play toolbar now has a Test Locally button and a Mantle dropdown, and Tools has a Mantle section. Settings are under Editor Preferences → Plugins → Mantle.

Then follow the Quick start to sign in and publish your first world.

Experimental dependency: Toolset Registry

Mantle Core lists Epic's Toolset Registry plugin as an optional dependency. Epic marks Toolset Registry as Experimental. It's off by default, Mantle Core doesn't turn it on, and without it the plugin works exactly the same.

Toolset Registry is only used for the AI agent tools. When you turn on Epic's Unreal MCP plugin (also Experimental), which brings Toolset Registry with it, Mantle registers a set of tools that Unreal's Model Context Protocol server offers to an AI agent, so the agent can check, preview or publish your place when you ask it to. If Epic discontinues Toolset Registry, only these agent tools are affected.

Working with the plugin

Where the tools are

  • Tools → Mantle, and the Mantle dropdown next to Play, hold the same commands: Test Locally, Stop Preview, Start a new place, Place settings, Check this place, Check what players receive, Save to Mantle, Publish, the vehicle, weapon, Cosmetics and Library tools, and signing in. See The Mantle editor tools.
  • The Mantle Scripts panel and Mantle Script Graph assets. See Editor setup.
  • The Mantle.Check console command, which runs Publish's check and export without publishing. See Checking from the console.
  • Editor Preferences → Plugins → Mantle: which world each level publishes to, and the Mantle client Test Locally uses. These settings are yours only. They're saved in your own editor settings, not shared with the project or your teammates.

From level to live world

  1. Build

    Start a new place and build it from meshes, lights and Mantle actors. Your own meshes, materials and Fab packs work too. See Building a place and Custom meshes and materials.

  2. Convert

    Turn cars into Mantle vehicles, and avatars, clothing, hair and emotes into avatar items, with Epic's plugins. See Vehicles, Avatars and emotes and Clothing, hair and accessories.

  3. Check

    Run "Check this place" and fix what it lists. See What "Check this place" catches.

  4. Test

    Press Test Locally and play your place in the Mantle game. See Testing with Test Locally.

  5. Upload

    Save to Mantle uploads a private draft, and Publish makes it live. Upload avatar items with the Cosmetics panel. See How publishing works.

Testing with Test Locally Live

Test Locally exports the level you have open and runs it in the Mantle game on your PC, with your scripts and UI. Nothing is uploaded or published, and you don't need to sign in. Press it again after a change to replace the running test.

  • Mantle Preview opens beside the editor. It says what Test Locally is doing, which Mantle client it found, whether the place's geometry, scripts and spawn are ready, and every message the game reports, including script errors. Under Export coverage it lists what the export kept, changed and left out. Copy messages copies them all.
  • The test runs offline. Anything that tries to reach Mantle's online services is blocked, and the panel counts it.
  • What your scripts save is kept between runs, separately for each level. Reset local data clears it so the next run starts fresh.
  • Stop or Stop Preview closes the test. It only closes the copy of Mantle the editor started, never one you started yourself, and the test also closes with the editor.
  • Test Locally looks for the Mantle you installed from Steam or the Epic Games Store. If it can't find it, choose Choose client... in the panel, or set Preview Client Executable under Editor Preferences → Plugins → Mantle to Mantle-Win64-Shipping.exe in the install's Mantle\Binaries\Win64 folder.
  • If your Mantle is too old for Test Locally, you'll see "This Mantle client (…, version …) is too old for Test Locally. Update Mantle in Steam or the Epic Games Launcher, then try again." You may also see "This Mantle client is too old for Test Locally; update it…" followed by the client's path and the reason.
Scripts run only in Test Locally

Play in Editor (PIE) and Simulate don't run Mantle places or scripts. Use Test Locally to try your place and its scripts, and publish when it's ready. To check what will publish without running anything, use "Check what players receive".

Updates

  • When a new version of Mantle Core is out, the Epic Games Launcher offers it as an update to the installed plugin.
  • A new plugin version can add things the released Mantle game can't read yet. If your place uses one, Publish says so, and Save to Mantle still works. See What stops a publish.

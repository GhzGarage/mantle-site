Mantle supports AI-assisted workflows in the Unreal editor. You can connect an AI agent to the editor with the Model Context Protocol (MCP), and the Mantle plugin gives it tools for much of what Mantle can do.

What an agent can do Live

When you ask it to, an AI agent can check your place, preview what players would receive, explain a problem the check found and publish the place. It can also check and upload avatar items, convert a character so it can be uploaded, and list your places on Mantle. When it converts a character, it makes the same choices as the Avatar section of the Cosmetics panel and answers in the panel's words.

The agent works in your open editor, with the same checks as the menus. It doesn't replace them. Anything you can do from Tools → Mantle, you can still do yourself.

For the full list of tools and what each one does, see Using an AI agent.

Setting it up Live

You need Epic's Unreal MCP plugin. Epic marks it Experimental. It's off by default, and Mantle doesn't turn it on for you. Without it, the Mantle plugin works exactly as it always has.

  1. Turn on Unreal MCP

    In Edit → Plugins, enable Unreal MCP. It turns on Epic's Toolset Registry plugin with it. Restart the editor when it asks.

  2. Start the server

    Run the console command ModelContextProtocol.StartServer. To start it every time you open the editor, turn on Auto Start Server under Editor Preferences → General → Model Context Protocol. By default it listens on http://127.0.0.1:8000/mcp. You can change the port and path in those same settings.

  3. Connect your agent

    Point your agent at that address. Any agent that can talk to an MCP server over HTTP will do. In Claude Code, for example, run claude mcp add --transport http unreal-mcp http://127.0.0.1:8000/mcp.

  4. Sign in yourself

    To publish, upload avatar items or list your places, sign in in the editor first. The agent never sees your creator token, and no tool asks for one. If an agent asks you to paste your token into its chat, don't.

Then ask your agent what you'd like done, for example "check my place and tell me what's wrong."

Good to know Live

  • It's experimental in Unreal. Epic's Unreal MCP and Toolset Registry plugins are both Experimental, so they may change or go away in a later Unreal release. If that happens, only the agent tools are affected. See Experimental dependency: Toolset Registry.
  • The editor has to be open. The agent works through your running editor, so the server has to be started each session unless you turned on Auto Start Server.
  • Anything new it uploads is Private. An agent can't make the rights declaration that sharing an item needs, so a new avatar item, vehicle, weapon or script package it uploads is Private. A vehicle, weapon or script package that's already in your library keeps its own setting: an agent publish doesn't change it. To make an item Public, upload it yourself from the Cosmetics panel, or publish the place from the Mantle Publish tab and choose Public. See The rights declaration.
  • You stay in control. The agent is told to publish only when you've asked for that publish. Publishing a place makes it live for players, so be clear about when you want it.
  • Check its work. An agent can make mistakes. Use Check this place and Check what players receive before you publish, as you would without one.

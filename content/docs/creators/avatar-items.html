In progress The Mantle Cosmetics tab in the editor publishes avatar items to the Mantle catalogue with one button. You pick what you're making, the asset and a name. The plugin checks it against Mantle's rules, exports it, makes a thumbnail, uploads everything and follows the item through screening. Players find published items on the Avatar screen, which is still in progress.

What you can make

The panel's first drop-down picks the kind of item, and the second picks its slot. Each kind has its own page with the rules its asset has to meet.

Everything in the catalogue is free. The panel has no price field, and paid items come later with the marketplace.

Publishing an item

  1. Sign in

    Uploading needs a creator token. See Signing in to publish. The top of the panel shows "Signed in as [your name]", or "Not signed in: Upload asks for a creator token (Tools > Mantle > Sign in with creator token)." If you aren't signed in, Upload to Mantle opens the sign-in window with "Sign in to publish this item to Mantle."

  2. Open the panel

    Choose Tools → Mantle → Cosmetics.... The Mantle Cosmetics tab opens, headed "Publish to the Mantle catalog".

  3. Pick the kind and slot

    Under "What are you publishing?", pick the kind (it starts on Clothing (3D)) and then the slot. A line under them describes what that kind takes.

  4. Pick the asset

    Under "Asset", choose it from your project. The picker only offers the right type of asset for the kind. If the name is empty, it's filled in with the asset's name.

  5. Fill in the kind's details

    Some kinds show extra sections. See The panel's fields.

  6. Name it

    Under "Listing", give it a Name (players see it in the catalogue) and an optional Description.

  7. Check it

    Check only runs every check and the export without uploading anything. Fix anything listed as a "Problem".

  8. Upload it

    Upload to Mantle checks again, then exports, uploads and publishes. It won't start while any check fails. See After you upload.

Socket offsets and the accessory's attachment use the same ranges: location up to 50 cm from the socket on each axis, rotation from -180 to 180 degrees (pitch, yaw, roll) and scale from 0.5 to 2. The attachment boxes stop at those values. Socket offsets let you type past them, and the check then refuses the value instead of clamping it.

You don't make the thumbnail yourself. The panel renders a 512 x 512 picture of the item every time it checks:

  • An avatar shows full body, head to toe, with its face.
  • 3D clothing shows on the body it was made on, framed on the clothing.
  • An accessory shows on its own, in a three-quarter view from above.
  • Hair, 2D clothing and emotes use the asset's own Unreal thumbnail.

If nothing can be rendered, the thumbnail is a plain dark square. Files and details, at the bottom of the panel, lists each file the item uploads with its size, and says how the thumbnail was made.

What the panel checks

Each check result is a line starting "Problem:" (it must be fixed), "Note:" (worth knowing, but it doesn't stop an upload) or "Done:" (something the plugin handled for you, such as scaling a texture down or uploading a lower LOD). When nothing is listed, you'll see "Every check passed." The line above the list says "Fix the problems below, then choose Upload to Mantle." or "Ready: choose Upload to Mantle."

These checks apply to every kind. The kind pages list the rest (skeletons, triangle and texture budgets, sizes and so on).

After you upload

The upload runs in the background with a progress bar, so you can keep working. The status line shows each stage:

  1. Checking which files Mantle already has...

    Files your account has already uploaded are skipped, so nothing is sent twice.

  2. Uploading and processing files: N of M ready...

    Mantle checks each file and screens it. In Files and details, each file shows "Uploading", "Being processed", "Being screened", "Waiting for a moderator", "Approved" or "Already on Mantle". A garment waits for the body it was made on to be approved first.

  3. Creating the item...

    Once every file is approved, the plugin creates the item from them.

  4. Screening the item...

    Mantle screens the item's thumbnail, name and description. If something is flagged, a moderator looks at it.

When it finishes, the status line says one of:

  • "Published [item]. Players can find it in the catalog now."
  • "Published [item]. A moderator will look at it; it appears in the catalog once approved."
  • "Published [item]. Mantle is still screening it; it appears in the catalog once it passes." (if screening is taking a while)

An item that hangs below the knee (footwear aside) is published with an extra line: "It hangs below the knee, so Mantle marks it "may clip in motion": the legs can show through it when the wearer moves."

Once approved, the item is listed in the catalogue for everyone, and players can find more of your items with "More by [creator]". If the panel stops following an item before it's decided, look for it on the Avatar screen: it shows up there once it passes.

Cancel stops an upload at any time, and closing the tab does the same. Everything already uploaded stays on Mantle: "Cancelled. Upload again to continue where it stopped."

Mantle checks a few things when it creates the item, and "Mantle refused the item" then gives the reason, for example:

  • "the accessory is N cm across, [slot] allows N cm" or "the accessory reaches N cm from its pivot, [slot] allows N cm"
  • "the avatar stands N cm tall, the minimum is 151.1 cm" (or "the limit is 218.1 cm")
  • "a hair item may use at most 4 textures", or "the item needs about N MB of GPU memory; the limit is 24.0 MB"
  • "An item name is 1 to 64 characters." (names can't contain invisible formatting characters either)

Changing an item In progress

Mantle can update a published item in place, but the Cosmetics panel doesn't offer it yet. If you change the asset, slot, name, description or any other setting and choose Upload to Mantle, the panel publishes a separate new item, and the old one stays in the catalogue.

When editing arrives, an edited item is checked and screened again like a new one, and it leaves the catalogue until the new version passes. Each edit counts towards the hourly item limit.

Delisting an item In progress

Delisting takes an item out of the catalogue for good. The panel can't delist yet. A delisted item can't be worn or edited, and players wearing it have it taken off (the Avatar screen tells them once). To publish it again, upload it as a new item.

Reports and takedowns

  • Players can report an item with Report this item at the bottom of its page on the Avatar screen. See Report an avatar item.
  • A moderator can delist any item.
  • If a moderator removes one of your uploaded files from your account (usually after a licence complaint), every item of yours that uses it is delisted, and that file can't be uploaded or used again.

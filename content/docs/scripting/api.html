API at a glance

This page lists everything your scripts can use. The API is the same in every language, but each name follows that language's usual style: FindByTag in Luau, findByTag in JS/TS, find_by_tag in Python. Service names such as World stay the same in every language. Members marked Server or Client only work on that side. Everything else works on both. Every member, with its types and a description, is in the full reference below, and in the generated type files (see Editor setup).

API versions

The current script API is 1.45, and the newest game release runs it. Members marked with a version, such as (API 1.9), were added in that version. When you publish, the Mantle plugin records the lowest API version your scripts actually use, not the version of the plugin.

  • The newest game release carries every member on this page from API 1.0 to 1.45, so scripts that use any of them publish and run today. Tween easing

Tween takes an optional easing style and direction, with the same curves as Roblox. The styles are Linear, Sine, Quad, Cubic, Quart, Quint, Exponential, Circular, Back, Bounce and Elastic. The directions are In, Out and InOut. The defaults are Linear and Out, and names aren't case-sensitive. Back and Elastic overshoot the goal before settling, but a shrinking scale never overshoots past zero, so objects don't flip inside out. Every player sees the tween in time, and players who join halfway through a tween still see the object in the right place. From API 1.8 the goal can also fade a light's LightColor or LightIntensity, or a mesh's Color.

Errors and limits

Check where the error came from and what kind it is

An ordinary error inside a callback stops only that one run of the callback, and the report shows where in your code it happened. Going over a CPU, memory or other platform limit is more serious: it stops the whole script that caused it, including its pending tasks and connections. Most platform limits stop the whole script: live clones (Assets:Spawn meshes included), active tweens, attributes, State, script-spawned lights, sound and effect plays, and outstanding timers and signal connections. Some limits only fail the one call, as an ordinary error you can catch, or with nil: vehicles, NPCs and joints (Spawn or Create), spatial queries, input bindings, open UI documents, DataStore pending writes and ordered requests, and UI:Create, which returns nil. Other scripts keep running either way. Server errors appear in the server log, and client errors appear in that client's log.

Every service and object in script API 1.45, matching the type files. The newest game release runs 1.45, so every member listed here publishes and runs today. Interaction

Service. Let players walk up to an entity and act on it with a key press, and hear when they do. The server decides everything: change things and listen to Interacted on the server. The client signals are for the local player and only for effects such as a sound or a glow. Added in API 1.38. A part is a named piece of an object, and "" (or leaving part out) means the whole object. An action is "Primary" (E on a keyboard) or "Secondary" (X on a keyboard), not case-sensitive. Every method errors with that entity no longer exists when the entity is gone.

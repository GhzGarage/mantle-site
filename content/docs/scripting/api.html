API at a glance

This page lists everything your scripts can use. The API is the same in every language, but each name follows that language's usual style: FindByTag in Luau, findByTag in JS/TS, find_by_tag in Python. Service names such as World stay the same in every language. Members marked Server or Client only work on that side. Everything else works on both. For the full list with descriptions, use the generated type files (see Editor setup).

Members marked with an API version, such as (API 1.2), were added in that version. A place with scripts records the API version of the editor that published it. A game build with an older API doesn't start that place's scripts, and logs Scripts not started for this place: this place needs script API 1.2; this build has 1.1. Update the game to run them. The rest of the place still loads and plays.

Tween easing

Tween takes an optional easing style and direction, with the same curves as Roblox. The styles are Linear, Sine, Quad, Cubic, Quart, Quint, Exponential, Circular, Back, Bounce and Elastic. The directions are In, Out and InOut. The defaults are Linear and Out, and names aren't case-sensitive. Back and Elastic overshoot the goal before settling, but a shrinking scale never overshoots past zero, so objects don't flip inside out. Every player sees the tween in time, and players who join halfway through a tween still see the object in the right place.

UI reference

UI:Create(kind) Client creates a UI node that stays on screen until you destroy it. The kinds are frame, text, image, button, toggle, list, grid, scroll and prompt. It returns nil once a script has 256 nodes.

Errors and limits

Check where the error came from and what kind it is

An ordinary error inside a callback stops only that one run of the callback, and the report shows where in your code it happened. Going over a CPU, memory or other platform limit is more serious: it stops the whole script that caused it, including its pending tasks and connections. The vehicle limit is the exception, and only fails that Spawn call. Other scripts keep running either way. Server errors appear in the server log, and client errors appear in that client's log.

Editor setup

The Scripts panel offers New Script…, Open, Open Scripts Folder, Open in VS Code (whole project), Check All and Regenerate Types. Regenerate Types writes type definitions for the Mantle API into ScriptTypes/ (mantle.d.luau, mantle.d.ts, mantle.pyi and mantle_api.json). The editor config files below are created automatically if they're missing.

LanguageFilesEditor
LuauScriptTypes/mantle.d.luau; .vscode/settings.json and Scripts/.luaurc (strict mode, @Shared/@Server/@Client aliases)VS Code with the Luau Language Server extension
TypeScript / JavaScriptScriptTypes/mantle.d.ts; project-root tsconfig.json (strict, allowJs, @Shared/* path alias)VS Code (built in)
PythonScriptTypes/mantle.pyiVS Code with Pylance; point python.analysis.extraPaths at ScriptTypes/

Check All checks your scripts for errors, but it doesn't run your game. Once it passes, publish a new revision with Mantle → Publish and join it in a separate client to test it. Changed files reload while you play (hot reload) only in development builds started from a place.json on disk.

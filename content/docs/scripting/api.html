API at a glance

This page lists everything your scripts can use. The API is the same in every language, but each name follows that language's usual style: FindByTag in Luau, findByTag in JS/TS, find_by_tag in Python. Service names such as World stay the same in every language. Members marked Server or Client only work on that side. Everything else works on both. Every member, with its types and a description, is in the full reference below, and in the generated type files (see Editor setup).

API versions

The current script API is 1.24. The newest game release runs API 1.3. Members marked with a version, such as (API 1.9), were added in that version. When you publish, the Mantle plugin records the lowest API version your scripts actually use, not the version of the plugin.

  • A place whose scripts only use API 1.3 or older publishes and runs today.
  • Members from API 1.4 to 1.24 are marked Next release. They're in the Mantle plugin and its type files, but publishing refuses a place that uses them until a game release that carries them is out. Save to Mantle still works. Publish stops with This revision is not compatible with the supported release matrix., and the Output Log gives the reason, such as This place needs script API 1.9, newer than the newest released game build's 1.3. Update the Mantle plugin and re-publish, or wait for the next release.
  • A game build with an older API doesn't start that place's scripts, and logs Scripts not started for this place: this place needs script API 1.2; this build has 1.1. Update the game to run them. The rest of the place still loads and plays.

Tween easing

Tween takes an optional easing style and direction, with the same curves as Roblox. The styles are Linear, Sine, Quad, Cubic, Quart, Quint, Exponential, Circular, Back, Bounce and Elastic. The directions are In, Out and InOut. The defaults are Linear and Out, and names aren't case-sensitive. Back and Elastic overshoot the goal before settling, but a shrinking scale never overshoots past zero, so objects don't flip inside out. Every player sees the tween in time, and players who join halfway through a tween still see the object in the right place. From API 1.8 the goal can also fade a light's LightColor or LightIntensity, or a mesh's Color.

Errors and limits

Check where the error came from and what kind it is

An ordinary error inside a callback stops only that one run of the callback, and the report shows where in your code it happened. Going over a CPU, memory or other platform limit is more serious: it stops the whole script that caused it, including its pending tasks and connections. Two limits are exceptions: the vehicle limit only fails that Spawn call, and the spatial-query limit only fails that query. Other scripts keep running either way. Server errors appear in the server log, and client errors appear in that client's log.

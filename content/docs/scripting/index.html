Scripting is in preview

Luau, TypeScript, JavaScript, Python and visual scripts run in published places, in the Mantle client and on its servers. The newest game release runs script API 1.37, so everything on these pages publishes and runs today except what's marked Next release. When a new version of the Mantle plugin adds members, they're marked Next release until a game release carries them (see API versions). Details on these pages may change before general release.

Five-minute start

  1. Find your level's folder

    Your level lives somewhere under Content/, for example Content/MyPlace/MyPlace.umap. Its scripts go in a folder called Scripts right next to it: Content/MyPlace/Scripts/.

  2. Make a Server folder inside it and add a file

    Or open the Mantle Scripts panel and choose New Script..., which creates the folders for you.

    Scripts/Server/Hello.luau
    print("Hello from the server!")

Players:OnPlayer(function(player)
	print(`{player.Name} joined`)
end)
    Scripts/Server/Hello.ts
    console.log("Hello from the server!");

Players.onPlayer((player: Player) => {
	console.log(`${player.name} joined`);
});
    Scripts/Server/Hello.js
    console.log("Hello from the server!");

Players.onPlayer((player) => {
	console.log(`${player.name} joined`);
});
    Scripts/Server/Hello.py
    print("Hello from the server!")

def on_join(player):
    print(f"{player.name} joined")

Players.on_player(on_join)

    Players:OnPlayer (JavaScript/TypeScript Players.onPlayer, Python Players.on_player) runs your function for every player already in the session, and again for each player who joins later. So the welcome still works if your script starts after someone is already in. The name it prints is the real player's name.

    If you only want players who join after you connect, use the PlayerAdded signal instead.

  3. Check and publish

    Run Check All in the Scripts panel (the Mantle Scripts button on the editor toolbar opens it), then publish with Tools → Mantle → Publish. Publishing creates a revision. When players join a session, it uses the published revision.

  4. Join in a separate client

    Start or request a session for your published place, then join it with the Mantle client. Anything a server script prints goes to the server log. Anything a client script prints goes to that client's log. Script messages appear under LogMantleScript and name the file they came from.

    Scripts don't run when you press the editor's Play (PIE) button. To try them without publishing, choose Tools → Mantle → Test Locally (see Testing with Test Locally). To test them with other players, publish and join the session with the Mantle client.

  5. Edit, recheck and republish

    Save your changes and publish a new revision. The next session uses it.

The three rules

RuleExample
1. Scripts are files in the Scripts folder beside the level.Content/Obby/Obby.umap → Content/Obby/Scripts/
2. The folder decides where a script runs.Server/ runs on the server. Client/ runs on each player's machine. Shared/ and any Modules/ folder hold libraries that only run when something requires them.
3. Tags connect scripts to things.Tag actors in the editor (Details → Actor → Tags), then World:OnTagged("killbrick", …).

The file extension picks the language: .luau/.lua, .ts, .js or .py, in lower case. You can mix languages in one place. Visual scripts are graph assets instead of files with an extension. They follow the same Server/ and Client/ rule, but there's no Shared/ for them.

Inside Server/, Client/ and Shared/, organize files however you like (Server/Combat/Guns.luau runs). A few rules apply:

  • Folder names must match exactly, including capital letters. server/ isn't recognized.
  • Files placed directly in Scripts/, or outside Server/, Client/ and Shared/, don't run. Tools → Mantle → Check this place lists each one as "Scripts/<path> is not inside Server/, Client/ or Shared/ (case-exact)." and you need to move or remove it. Publish runs the same check first. A file with any other extension gets "Scripts/<path> has an extension Mantle cannot map to a script language."
  • Script paths can use only the plain letters A to Z and a to z, digits, _, . and - (no spaces or accented letters), up to 200 characters.
  • A script's name, which is its file name without the extension, is 1 to 80 characters.
  • Each file can be up to 1 MiB.

Content/MyPlace/

  Scripts/
    Server/            runs on the server
      Rounds.luau
      Checkpoint.ts
      Leaderboard.py
      Modules/         server-only libraries (require them)
    Client/            runs on every player's machine
      Hud.luau
      Welcome.js
    Shared/            libraries both sides can require
      Config.luau
  UI/                  UI documents that client scripts open
    shop.rml
    shop.rcss

A UI/ folder beside Scripts/ holds UI documents: screens written as markup and stylesheets that client scripts open with UI:OpenDocument (API 1.31).

A Packages/ folder beside Scripts/ holds script packages: scripts you publish to the library for other creators, and that other creators' places run from their storage, anchored by Script Points (API 1.35).

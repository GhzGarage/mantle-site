Installing In progress

Mantle is in closed testing on Steam and the Epic Games Store. You only download it once. After that, you can join any published world without downloading anything extra.

Updates come through Steam or the Epic Games Store, just like any other game. There's no separate launcher to install.

If your copy is out of date, you'll see this message when you try to join a world: "This version of Mantle is out of date. Update it through Steam or the Epic Games Store, then try again."

Platforms and requirements

  • Live Windows PC.
  • Planned Consoles and mobile are being looked into.
  • Minimum PC specs will be shared later. For now, go to Settings and pick a "Graphics quality" preset, or use "Auto-detect quality" to match your PC.

Signing in Live

You're signed in automatically, using the store you started Mantle from:

  • Steam: your Steam account signs you in. There's nothing to enter.
  • Epic: Mantle uses your Epic Games Launcher sign-in or a saved login. If neither is available, Epic's own sign-in window opens.
  • Launched some other way? You'll see "Start Mantle from Steam or the Epic Games Launcher to sign in."

The sign-in screen shows "SECURE SIGN-IN" and "Welcome to Mantle".

  • On Steam, it says "Your Steam account identifies you to Mantle. Steam signs you in; there is nothing to enter here."
  • On Epic, it says "Your password is entered only in Epic's own sign-in window." Mantle never sees your password.
  • If something goes wrong, press "TRY SIGN-IN AGAIN".

If you use Epic, Mantle asks to see your basic profile, friends list, online status and country. Your display name is the name you use on Steam or Epic, so you change it there, not in Mantle. See Your account for what's stored.

Finding worlds Live

The bar across the top of the screen has:

  • "DISCOVER" and "AVATAR"
  • a "Search worlds and creators" box (on a gamepad, press Y to jump to it)
  • your friends (click to open the Steam or Epic overlay)
  • your profile and the settings gear

Discover page

  • FEATURED: hand-picked worlds in a carousel, with "PLAY" and "DETAILS".
  • Rows of worlds: "Friends are playing", "Jump back in", "Top 10 this week", "New and rising" and "Your favorites".

Search

Search checks world names, descriptions and creators. You can sort results by "Best match", "Most played" or "Newest". The sort applies to every result, not just the ones on screen.

Search results and "See all" on "New and rising" load more worlds as you scroll. A world that's already on screen isn't shown twice.

World and creator pages

A world's "About" tab shows its creator, "Players per server: up to N", its version ("Revision N") and "More from [creator]". Press "PLAY" to join.

Click a creator's name to see their page and all their worlds.

Community servers Live

Some worlds also have servers run by players. If a world allows them, its page has a "Servers" tab next to "About" that lists them. "PLAY" always puts you on an official server. To play on a community server, pick it from this list.

  • Each server shows its name, "hosted by" and the host's name, how long it's been up, its region and how full it is.
  • The status is "VERIFIED", "NOT YET VERIFIED", "FULL" or "OLDER VERSION". You can join any server that isn't full.
  • Press "JOIN" on a server's row. The first time, Mantle explains that community servers are run by other players, not by Mantle. Press "CONTINUE" to join.
  • Each row has a "Report" link.
  • If there are none, you'll see "No community servers right now" and "Play still works: it starts an official server for you and anyone who joins."
  • If the server has gone by the time you join, you'll see "That server is no longer available. Refreshing the list…"

Private servers Live

A private server is a server for one world that only its members can join. You'll find "PRIVATE SERVERS" at the top of the world's "Servers" tab, above any community servers. You can make one for your own worlds, and for other worlds whose creator allows it.

  1. Create it

    Give it a name if you like ("Name it (optional)", up to 48 characters) and press "Create private server". You're its owner.

  2. Invite friends

    Press "Invite friends" to get an invite code. It's shown once, so press "Copy" and send it to your friends in Steam or Epic chat. A code works for 7 days.

  3. Redeem a code

    Your friend opens the world's page, goes to "Servers", types the code into "Enter an invite code" and presses "Redeem". They're now a member and can join whenever they like. A code redeemed on another world's page still works: they'll find the server on that world's "Servers" tab.

  4. Join

    Press "Join" on the server's row. If it isn't running, Mantle starts it for you.

  • Each row shows whether you're the "Owner" or a "Member", how many members it has, and "Nobody playing" or how many are playing. A server that can't be joined shows "Unavailable" or "Suspended".
  • Owners press "Manage" to rename the server, make invite codes, see and remove members, or delete the server. Deleting it disconnects anyone playing and stops its codes working, and can't be undone.
  • Members press "Members" to see who else is in it, or "Leave server" to leave. You'll need a new invite code to get back in.
  • You can own up to 10 private servers, each with up to 200 members. Only one of your private servers can run at a time.
  • Private servers that Mantle runs come with a monthly amount of free play time for their owner. When it's used up, nobody can start that owner's servers until it resets, and joining says when.
  • An owner can also run a private server on their own PC. See Private community servers.

Joining a world Live

  1. Press Play

    Mantle looks for a server for that world.

  2. Find or start a server

    If a server has room, you join it, even if a game is already under way. If not, Mantle starts a new server near you. The screen stays on "Finding a server" while it starts.

  3. Load in

    Mantle loads the world and connects you to the server.

While you join, the screen shows "JOINING" and the steps "Finding a server / Reading the world / Building the world / Connecting". You'll also see "CANCEL", "BACK" and "TRY AGAIN".

Servers hold 16 players by default, or up to 100 if the world allows it.

If the world can't be loaded after you've connected, Mantle takes you back to the home screen and shows "That world couldn't be loaded. Try joining again." (or "That world couldn't be loaded:" followed by the reason).

If you're disconnected while playing, you're taken back to the home screen with the reason, for example "The connection to the server was lost." or "You were removed from this world." A world can add its own reason when it removes someone.

What you need to know

  • Live The Mantle app runs on Windows and comes through Steam and the Epic Games Store. You use it to browse worlds, join them and play.
  • Live Official servers run worlds for players. Mantle starts one near you when you press Play.
  • Live Community servers let players run a world server on their own machine. Players find them on a world's Servers tab. See Community-hosted servers.

What happens when you press Play Live

  • You join an official server. If one for that world has room, you join it. If you already had a spot on one, you get it back. Otherwise Mantle starts a new one near you, which can take up to about 5 minutes. See How many players.
  • Play never puts you on a community server. You join those from the world's Servers tab.
  • Your copy of Mantle must be up to date. If it isn't, you're turned away with "This version of Mantle is out of date. Update it through Steam or the Epic Games Store, then try again."
  • The world loads on your PC, along with any meshes, materials and textures its creator uploaded, then you connect.
  • New versions of a world: if the creator is rolling out a new version gradually, you might get either the new version or the current one.
  • When the last player leaves, the server stops. Players who join later start from the top.

How many players

  • Live Worlds take 16 players by default and up to 100 per server. A community server can set a lower limit, but never a higher one than the world's.
  • In progress Tuning and larger-scale tests.

Performance testing Live

We load-test Mantle game servers with bot players joining over the internet, the same way real players do. Each bot walks, sprints, jumps and stands around at random. Based on that testing, here is what a server uses at each player count:

  • Fast joins: all 50 players joined in about 40 seconds.
  • Room to grow: a single CPU core ran 50 players using about a quarter of its capacity, and memory stayed flat for the whole test.

  • Linux figures assume a server install without a desktop, such as a VPS or a spare machine. It's the lightest way to host.
  • Windows figures assume Windows 10 or 11 with nothing demanding running alongside. If you also play on the same PC, you'll need more on top.
  • Single-core speed matters most. A Mantle server does most of its work on one core, so a modern desktop or server CPU with good per-core speed goes further than more, slower cores.
  • Upload speed is usually the limit at home. Check your connection's upload speed (not download) before hosting a large world.

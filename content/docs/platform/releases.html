Updating Mantle Live

  • Updates reach players through Steam's and Epic's normal updates. There's no separate Mantle launcher.
  • Out-of-date copies are turned away when you join a world, with "This version of Mantle is out of date. Update it through Steam or the Epic Games Store, then try again." You can only join a server running the same build as your game, and that includes community servers.

New features and publishing Live

Before a world is published, Mantle checks that the released game can read everything in it. A world that uses something the released game can't read yet, such as a newer script API, a new kind of object or a new material setting, can be saved to Mantle but not published. Publish stops with "This revision is not compatible with the supported release matrix." The report says what is in the way. For a script API that is too new, it reads "This place needs script API N.M, newer than the newest released game build's X.Y. Update the Mantle plugin and re-publish, or wait for the next release." For a new kind of object it reads "This place uses [type], which the released game can't build yet." Publish again once the game can read it. See What stops a publish.

  • Live Clothing skinned to its root bone: clothing with all its weight on the root bone used to stay stiff in the game. Now the upload copies the skin of the body it was made on and says so under Files and details. If it can't, the upload stops with a Problem that says how to fix it. See Messages and how to fix them.
  • Live Throwing spears: every spear can be thrown. On a lone spear, hold aim to raise it and click to throw it toward the crosshair; aiming replaces the block. It sticks where it lands, can be picked up, and leaves your backpack when thrown. Beside a shield, aim raises the guard and a click throws the spear. The crosshair shows while a thrown weapon's throw is raised. See Settings and their ranges and Tools, backpack and weapons.
  • Live Walking pace: on a keyboard you start out walking, and Left Ctrl now switches to jogging instead of to walking. A gamepad ignores it: the left stick still walks or jogs by how far you push it. See Controls.
  • Live Thrown weapons: a thrown knife or axe shows its extra parts in flight and where it sticks, and leaves your backpack as soon as you throw it. It lands as a pickup, and whoever picks it up gets it again, the thrower included. See Settings and their ranges and Tools, backpack and weapons.
  • Live Seats: any prop can have seats, and each seat has its own "Sit" prompt, reach and facing, so a long bench works from either end. A place's seats are saved with the place. Jumping does nothing while seated, and you stand up jogging if you hold a move key. See Seats.
  • Live Skin under clothing: clothing hides only the skin it fully covers, so skin shows through cutouts and between straps, and skin near a garment's edges stays visible. Items already published get this too, with nothing to upload again. See How clothing fits every body.
  • Live No sidestepping: players no longer step aside when another player bumps into them or walks up to them. Nothing steps aside for bumps today.
  • Live Screen reader on by default: Mantle turns on screen reader support (Windows Narrator) when you play. Buttons that had only an icon, such as the arrows on the Discover rows, the favorite star, the Settings gear and the Close button, now have names a screen reader can read. See Menu and settings.
  • Live Terms notice at sign-in: the sign-in screen says "By signing in you agree to the Terms of Service and Privacy Policy", with links to both. See the privacy notice.
  • Live Server terms for server keys: to create a community server key, you read the server terms and turn on "I agree" in Settings → Account → Hosting. CREATE SERVER stays off until you do. The server package includes the terms, a README and an example settings file. See Before you start.
  • Live Other players see what you wear: a private avatar item shows to other players while it's in your saved look. Only you can still find, get or wear it. A change you haven't saved yet shows them a stand-in. See Public and private items.
  • Live Weapon icon on the hotbar: weapons and consumables you make with the weapon builder show their library picture on the hotbar in the game. See Publishing a weapon.
  • Live Hair: OBJ hair that lies on its side is turned upright for you before it's fitted. Dense hair packs over the 14,000-triangle limit now come out thin but even, instead of patchy, and a pack that still can't fit uploads with a warning instead of an error. See Hair bought for another head.
  • Live Keep the face: when you keep a character's face, the Fat and Muscularity sliders now start from the character's own build instead of MetaHuman's default. See The face.
  • Live Data cleanup: a deleted account's personal data is removed right away, and the empty record left behind is removed after 30 days. A draft is deleted 180 days after you last saved it, and a place you never published a year after you last saved it. See Account deletion and data retention and the privacy notice.

Game server updates Live

Updates to official servers don't interrupt anyone who is already playing.

  • Live Community servers update themselves. Mantle only accepts the two newest server builds. mantle-server checks for a new signed build about once an hour, installs it, and switches once the server is empty (or as its autoUpdate setting says). Operators can also run mantle-server update or rollback. The first install still comes from Settings → Account → Hosting. See Server builds and updates.
  • Live New versions of a world: community servers keep running the version they started with, and restart onto the newest one once they're empty.

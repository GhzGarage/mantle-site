Updating Mantle Live

  • Updates reach players through Steam's and Epic's normal updates. There's no separate Mantle launcher.
  • Out-of-date copies are turned away when you join a world, with "This version of Mantle is out of date. Update it through Steam or the Epic Games Store, then try again."

Game server updates Live

Updates to official servers don't interrupt anyone who is already playing.

  • Live Community operators download the current server package from Settings > Account > Hosting. Mantle only accepts recent server packages, so update yours when a new one comes out. See While it's running.
  • Live New versions of a world: community servers keep running the version they started with, and restart onto the newest one once they're empty.

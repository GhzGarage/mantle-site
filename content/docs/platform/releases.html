Updating Mantle Live

  • Updates reach players through Steam's and Epic's normal updates. There's no separate Mantle launcher.
  • Out-of-date copies are turned away when you join a world, with "This version of Mantle is out of date. Update it through Steam or the Epic Games Store, then try again." You can only join a server running the same build as your game, and that includes community servers.

New features and publishing Live

A new feature can reach the Mantle plugin before the game release that can show it. Publishing waits for players: a world that uses something the released game can't read yet, such as a newer script API, a new kind of object or a new material setting, can be saved to Mantle but not published. Publish stops with "This revision is not compatible with the supported release matrix." The feature can be published once the release that reads it is out. The docs mark these features Next release.

What's new

29 September 2026

  • Live World screens: worlds can open their own shops, menus, inventories and dialogue, which you can use with a mouse, keyboard or gamepad, close with Esc or B, and read with a screen reader. See World screens and menus.
  • Live My Places: creators can list, open and delete their worlds and drafts from Settings > Account on the home screen. See My Places.
  • Live World messages from a world's scripts now show on screen: short lines in the top-left corner and pop-ups at the top of the screen.
  • Live Always a character: if something is sitting on the spawn point when you join, such as a parked car, you're placed on clear ground nearby instead of being left without a character.
  • Live Parked cars stay put when you walk or sprint into them.
  • Live Joining a world under way: hanging and resting objects, like a lamp on a rope, now show where everyone else sees them.
  • Live Pushing things: walking into loose objects pushes them more gently, and you no longer vault or climb over light objects that slide away under you.
  • Live Rain now shows in worlds that have it.

Game server updates Live

Updates to official servers don't interrupt anyone who is already playing.

  • Live Community servers update themselves. Mantle only accepts the two newest server builds. mantle-server checks for a new signed build about once an hour, installs it, and switches once the server is empty (or as its autoUpdate setting says). Operators can also run mantle-server update or rollback. The first install still comes from Settings > Account > Hosting. See Server builds and updates.
  • Live New versions of a world: community servers keep running the version they started with, and restart onto the newest one once they're empty.

Updating Mantle Live

  • Updates reach players through Steam's and Epic's normal updates. There's no separate Mantle launcher.
  • Out-of-date copies are turned away when you join a world, with "This version of Mantle is out of date. Update it through Steam or the Epic Games Store, then try again." You can only join a server running the same build as your game, and that includes community servers.

New features and publishing Live

A new feature can reach the Mantle plugin before the game release that can show it. Publishing waits for players: a world that uses something the released game can't read yet, such as a newer script API, a new kind of object or a new material setting, can be saved to Mantle but not published. Publish stops with "This revision is not compatible with the supported release matrix." The feature can be published once the release that reads it is out.

Game server updates Live

Updates to official servers don't interrupt anyone who is already playing.

  • Live Community servers update themselves. Mantle only accepts the two newest server builds. mantle-server checks for a new signed build about once an hour, installs it, and switches once the server is empty (or as its autoUpdate setting says). Operators can also run mantle-server update or rollback. The first install still comes from Settings → Account → Hosting. See Server builds and updates.
  • Live New versions of a world: community servers keep running the version they started with, and restart onto the newest one once they're empty.

Community hosting lets players run world servers on their own machines. You can host any world you published, and any world whose creator allows community servers. Players find your server on that world's Servers tab.

Setting up a self-hosted server Live

You run a community server with a small program called mantle-server. It starts the Mantle game server, registers it with Mantle so players can find it, and keeps it running. It works on Windows and Linux.

Before you start

  • A machine that meets the recommended specs for the number of players you want.
  • A server key for your Mantle account. Create one in the Mantle app under Settings > Account > Hosting: type a server name (3 to 48 characters) and press Create server. Players see that name in the world's server list. The key is shown only once, so copy it somewhere safe. Anyone holding it can run a server as you. Each account can have 5 servers, and each server has one key.
  • The Mantle server package, which contains mantle-server, the game server and the server terms. Download it from Download server build in the same Hosting section. Open downloads it in your browser, and Copy link copies a link you can use on the machine that will run the server. Each link works for an hour.
  • A public address players can reach: your public IP address or a domain name that points to it.
  • A UDP port you can open. The default is 7777.
  1. Unpack the package

    Extract it into its own folder and run every command below from inside that folder.

  2. Create your settings file

    Run mantle-server init. It asks for the Mantle API URL, your server key, the world's place id (plc_…), a server name and your public address, then writes them to server.json. You can pass any of them as flags instead (see below). Read the server terms (SERVER_TERMS.md) and add -accept-terms to accept them. The server won't start until you do.

  3. Open the port

    Allow the UDP port through your firewall. If the machine is behind a home router, forward the port on the router too. On a VPS, also open it in your provider's firewall or security group.

  4. Check your setup

    Run mantle-server check. It checks your settings, confirms your server key works and makes sure the port is free on this machine. It also prints the firewall command for your system.

  5. Start the server

    Run mantle-server run. It registers your server, downloads the world, starts the game server and lists it on the world's Servers tab. Leave it running for as long as you want to host.

  6. Stop the server

    Press Ctrl+C to shut it down cleanly.

Example
mantle-server init -name "Sunset Hills EU" -address 203.0.113.10 -port 7777 -max-players 32 -region EU -accept-terms
mantle-server check
mantle-server run

You can edit server.json by hand at any time. Restart mantle-server afterwards.

While it's running

  • Automatic restarts: if the game server crashes, mantle-server restarts it. After 10 crashes in 10 minutes it stops, so check the logs.
  • Daily restart: the game server has to restart within 24 hours of starting. Near the end of that time, mantle-server restarts it as soon as it's empty, or at the last minute if players are still on it.
  • New versions of the world: when the creator publishes a new version, your server keeps running the one it started with and players can still join it. It restarts onto the new version once it's empty.
  • New server builds: Mantle only accepts recent server packages. If yours is too old, mantle-server stops and logs "this package version is no longer accepted" with the current version. Download the new package from Settings > Account > Hosting, unpack it into a new folder, copy your server.json across and start it from there.
  • Registration can be refused if the key already has a running server, the world isn't published, you aren't allowed to host it, your server package is out of date, your public address doesn't match where the server is connecting from, or the key is registering too often.

What players see Live

Players find and join community servers from a world's Servers tab. It says "Community servers are run by players. Play puts you on an official server; to play on one of these, join it here." If none are running, it shows "No community servers right now" and "Play still works: it starts an official server for you and anyone who joins."

Each server shows its name, region, player count, who hosts it and how long it's been up. Only servers that are running and responding are listed, and server addresses are never shown.

  • Badges: "Verified" (players have joined it), "Not yet verified", "Full" and "Older version" (it's still running an earlier version of the world). Only full servers can't be joined.
  • First join shows a one-time notice: "Community servers are run by other players, not by Mantle. Mantle's safety tools still work here, but the server owner controls the experience."
  • If a server disappears, players see: "That server is no longer available. Refreshing the list…"
  • Play always uses official servers. Players only reach a community server by choosing it. Every server in the list has a Report link.

Controls

  • Live Hosting settings: Settings > Account > Hosting lists your servers with their status (Online, Starting or Offline) and player count. Create a server there to get its key, or press Revoke to cancel a key. Revoking shuts down a server running with it straight away, and can't be undone.
  • Live Creator opt-in: by default, only a world's owner can host it. Turn on Allow Community Servers on the world's Mantle Place Settings actor in the editor, then publish to let other players host it. If you turn it off later, servers already running keep going, but new ones can't start.
  • Live Moderators can shut down any community server, and can see which server and owner are behind a reported session.

Trust and safety

  • Saved data stays separate: each community server has its own saved data, so it can never touch a creator's official data.
  • Operators can't see players' network addresses.
  • Mantle's safety tools, including reporting and blocking, work on community servers the same way as on official ones.
